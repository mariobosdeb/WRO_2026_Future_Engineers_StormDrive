## Documentation principle

The repository separates three kinds of information:

1. **Manufacturer reference** — information supplied with the PiCar-B kit.
2. **StormDrive implementation** — code, wiring, mechanical design and decisions created by the team.
3. **Measured results** — values obtained from the team's own tests.

This distinction is important for reproducibility and for demonstrating the team's own engineering work.

## Finalization rule

The repository is not considered final until the actual V2 competition configuration, final source code, wiring, mechanical files, vehicle photos, challenge videos and measured engineering evidence have been added and verified.
