# Contributing

Keep changes reviewable and tie claims to evidence.

- Keep V1 archives separate from the current V2 source and photos.
- Write project documentation in concise English.
- Mark unknown facts with `TODO(team): ...` and add the item to [TODO.md](TODO.md).
- For physical results, record date, vehicle revision, source commit, calibration, mode, layout, result, time and evidence link.
- Preserve failed attempts and explain what changed as a result.
- Do not commit raw debug recordings, secrets or per-car calibration data. See [.gitignore](.gitignore).
- Check all relative Markdown links and identify whether a result came from the simulator or the physical car.
