# StormDrive V2 — WRO Future Engineers 2026

Existing project documentation identifies StormDrive V2 as the vehicle intended for the Europe-stage entry. V1 is a separate historical vehicle from the Romanian national stage; the earliest team prototype is separate from both.

The repository contains V2 source code and team-reported testing summaries. It does not contain dated physical run records or a frozen final configuration. See [Status and Evidence](../docs/status.md).
