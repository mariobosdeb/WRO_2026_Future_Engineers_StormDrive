# V2 Software Reference

StormDrive V2 software is in [`src/v2/`](../src/v2/README.md). It includes OpenCV perception, estimators, Open and Obstacle drivers, a C++17 lattice planner, a separate parking entry point, simulator, calibration, recording and replay tools.

Adeept examples are retained as vendor reference in [`vendor/adeept-picar-b2/`](../vendor/adeept-picar-b2/README.md); they are separate from the StormDrive challenge logic. Package versions and a fresh-install guide are not yet recorded.
