# StormDrive V1 CAD Archive

The eight STL files in this folder and their descriptions come from the historical V1 mechanical documentation. They describe the national-stage vehicle, not the Adeept-based V2.

| File | Part described in V1 notes |
|---|---|
| `RCcar_1.stl` | Internal front-steering pivot mechanism |
| `RCcar_2.stl` | Front steering housing |
| `RCcar_3.stl` | Steering linkage block |
| `RCcar_4.stl` | Servo-to-linkage connector |
| `RCcar_5.stl` | Main chassis base |
| `RCcar_6.stl` | Front assembly structural mount |
| `RCcar_7.stl` | Assembly fastener/locking part |
| `RCcar_8.stl` | Drivetrain coupler |

These descriptions are copied from team notes. Verify dimensions and fit before reuse. The V1 notes also describe a front DFRobot HuskyLens mount; that is not a V2 design detail.
